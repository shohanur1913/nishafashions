# Nisha Fashions Wear (NFW) Website

## Project Development Outline (PDO)

**Project:** Nisha Fashions Wear Website\
**Domain:** `nishafashions.com`\
**Document:** Complete Scratch-Build PDO\
**Primary Goal:** Buyer-focused apparel sourcing/export website with
basic SEO, mobile optimization, enquiry conversion, and clear
business-model communication.

------------------------------------------------------------------------

# 1. Project Objective

The website will be built from scratch as a modern, professional,
buyer-focused website for **Nisha Fashions Wear (NFW)**.

The primary objective is not to create a large corporate website. The
objective is to make an international apparel buyer understand within
the first 5--10 seconds:

1.  What NFW does
2.  What product categories NFW handles
3.  How NFW manages production
4.  Why a buyer should work with NFW
5.  Which markets NFW has experience with
6.  How to send a requirement or request a quotation

The website must present NFW as a **Bangladesh Apparel Manufacturer &
Sourcing Partner**, while clearly explaining that production is handled
through a selected/trusted factory network according to product,
quantity, quality and buyer requirements.

The website must **not falsely claim that NFW owns or operates its own
factory**.

NFW does not have to be presented as an owner of a factory.

The website should communicate the following model clearly:

> NFW works with selected and trusted production facilities according to
> product type, quantity, quality requirements and target price, while

-   "Our manufacturing facility"
-   "We own multiple factories"
-   "Our factory produces..."

Unless separately verified and approved by the client.
